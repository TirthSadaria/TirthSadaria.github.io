HIVE: Multi-Robot LiDAR SLAM

A fleet of TurtleBot3 robots maps an unknown world together: each runs LiDAR SLAM and their maps merge into one in real time.

Nov – Dec 2025 · Pair project with Shreya Kalyanaraman · ENPM700

  • Scalable (N)Robots
  • slam_toolboxSLAM
  • TDD + CIProcess

Problem

Several robots can map a space faster than one, but they start without a shared frame and must combine partial maps on the fly.

Approach

  1. Designed a decentralized architecture: one namespaced SLAM Toolbox instance per robot, with a map-merge node fusing the occupancy grids.
  2. Wrote the exploration controller in C++ using a state pattern, with a launch file that scales the robot count.
  3. Worked test-first with GTest, GitHub Actions CI and Codecov coverage reporting.
  4. Containerized the stack in Docker for repeatable multi-agent testing.

Results

  • Multi-robot mapping with live map merging in Webots, built and tested through CI.
