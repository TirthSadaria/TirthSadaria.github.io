Autonomous Rover

A ground robot I built and programmed alone over one semester, from the first motor test to a fully autonomous pick-and-place challenge run.

Spring 2025 · Solo project · ENPM701 Autonomous Robotics

  • SoloBuild
  • CompletedFinal challenge
  • 12 videosBuild log

Problem

Build one robot that can drive, sense, see and grasp, then complete the course's grand-challenge mission with no human input.

Approach

  1. Brought up a 4WD chassis on a Raspberry Pi with motor drivers, then added teleoperation with a live camera feed and ultrasonic ranging.
  2. Added a servo gripper and closed the motor loop with encoder feedback and a tuned PID controller.
  3. Wrote drivers for the Picamera2 and a BNO055 IMU, and fused them for localization with an Extended Kalman Filter in ROS 2.
  4. Built OpenCV pipelines for color-target tracking and arrow detection that steer the robot.
  5. Combined tracking, navigation and grasping into an autonomous find, pick and deliver routine.

Results

  • Completed the final grand-challenge mission autonomously.
  • Documented each stage of the build in 12 videos, linked below.
